RAVIYA ACCOUNT STORE WEBSITE

HOW TO ADD OR EDIT PUBLIC ACCOUNT LISTINGS:
1. Open your GitHub repository.
2. Open products.json.
3. Tap the pencil (Edit this file).
4. Replace the sample information, then Commit changes.
5. Wait a short time for GitHub Pages to update.

Each account object follows this format:
{
  "id": "account-002",
  "title": "PRIME 7 Account",
  "price": "Rs. 12,000",
  "prime": "PRIME 7",
  "level": "LV 80",
  "kit": "KIT 500+",
  "notes": "Best emotes and bundles",
  "image": "images/account1.jpg"
}

For images, upload the image into an images folder in the repository, then use a path such as images/account1.jpg.
Keep valid JSON syntax: double quotes around keys/text, commas between objects, no comma after the last object.
